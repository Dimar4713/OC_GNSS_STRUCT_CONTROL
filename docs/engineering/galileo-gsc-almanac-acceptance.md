# Galileo GSC acceptance scope

Acceptance for this phase requires:

1. Official GSC source semantics documented.
2. Latest-link discovery restricted to the reviewed GSC host/path and supported XML filename families.
3. Offline XML parsing through the same semantic record model.
4. SHA-256 provenance retained.
5. Semicircle and nominal-orbit conversions explicit.
6. `wna` remains modulo-4; no hidden absolute-week reconstruction.
7. Missing fields, duplicate SVID, invalid XML/ranges and network failure fail closed.
8. Consolidated Preview exposes both online and offline operator paths.
9. No runnable `ScenarioConfig` promotion in this phase.
