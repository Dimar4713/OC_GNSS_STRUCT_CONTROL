# ADR-0004: Receding-horizon impulsive MPC

Status: accepted.

Decision: use CVXPY convex subproblems with time-varying dynamics matrices supplied by the propagation/linearisation backend. Optimise total L1 impulse, fleet resource balance via `z`, tracking and safety penalties while keeping declared hard constraints hard.

Consequence: only the first manoeuvre is applied before replanning. Numerical safety validation remains a separate execution gate.
