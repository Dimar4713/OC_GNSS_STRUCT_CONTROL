# ADR-0002: DSST for design fidelity

Status: accepted, implementation tracked by #6.

Decision: use Orekit DSST as the design-level semianalytical propagator between analytic screening and numerical validation.

Rationale: design optimisation needs long-horizon mean-element behaviour at lower cost than full numerical propagation while retaining configurable perturbation physics.

Consequence: all design mean elements must name the DSST/force-model definition used to generate them.
