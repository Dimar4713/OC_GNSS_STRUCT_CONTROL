# ADR-0003: D'Amico ROE for relative control

Status: accepted.

Decision: represent relative control state with D'Amico ROE and use `delta_lambda = delta_M + delta_omega + cos(i_ref) delta_Omega`.

Rationale: the variables map naturally to formation/constellation relative geometry and support linearised control while separating phase, eccentricity and inclination-vector effects.

Consequence: conversions and units are centralized; controller code must not invent alternative phase definitions.
